# Tornado Tattoo

Static website for Tornado Tattoo in Oklahoma City.

## Preview locally

No build step is required. Double-click `index.html`, or run a local web server:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Deployment

The site can be deployed on any static host. Publish the repository root and keep the existing file paths intact.

## Contact links

The website directs consultation requests to the shop phone, email address, and the official [Tornado Tattoo Instagram account](https://www.instagram.com/tornadotattoo/).
